## 2. Создать окружение

В той же папке создал окружение и активирорал его:

| Шаг | macOS / Linux | Windows (PowerShell) |
|---|---|---|
| создать | `python3 -m venv .venv` | `py -m venv .venv` |
| активировать | `source .venv/bin/activate` | `.\.venv\Scripts\Activate.ps1` |

В начале строки терминала появилась `(.venv)`. Выберите этот интерпретатор
в VS Code: внизу справа стоит `.venv`.

## 4. Вынести расчёты в модуль

Создал рядом с `trip.py` файл `calculator.py` и перенес в него две
функции — `calculate_total` и `calculate_average`. В `trip.py`
вместо них в начале файла, рядом с импортом Rich, импортировал их:

```python
from calculator import calculate_total, calculate_average
```

Запустл `python trip.py`: отчёт выгляит таким же, как в пункте 1.
