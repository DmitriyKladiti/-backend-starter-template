# Cafe Report

Программа читает заказы кофейни из файла `data/orders.csv` и печатает отчёт:
количество заказов, выручку, средний чек и суммы по официантам.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## Запуск

Команды выполняются из корня проекта — из папки, в которой лежит код программы.

```
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` может потребоваться `py`, а окружение активируется
командой `.\.venv\Scripts\Activate.ps1`.

## Ожидаемый результат

```
ОТЧЁТ ПО ЗАКАЗАМ
----------------------------------
Заказов: 6
Выручка: 3 702,00 ₽
Средний чек: 617,00 ₽
----------------------------------
Анна Петрова      770,00 ₽
Игорь Смирнов     1 793,00 ₽
Мария Ким         1 139,00 ₽
```

Тесты дают строку `Ran 9 tests` и `OK`.

И тесты и отчет выводятся в ожидаемом виде!

Структура проекта:

```
praktikum-01-cafe-report/ (корневая папка проекта)
├── .env 
├── .gitignore
├── README.md
├── requirements.txt (содержит зависимости проекта, в это проекте их нет, поэтому окружение небыло создано)
├── app/ (главная папка проекта)
│   ├── __init__.py (нужно указывать во всех папках, чтобы они оприделялись как пакеты)
│   ├── main.py
│   ├── services/ (отвечает за основной функционал)
│   │   ├── __init__.py
│   │   ├── orders.py
│   │   └── report.py
│   └── utils/ (папка вспомагательных функций)
│       ├── __init__.py
│       ├── money.py
│       └── text.py 
├── data/ (данные о заказах, лежат отдельно от кода)
│   └── orders.csv
├── docs/ (подробное описание проекта)
│   └── project.md
└── tests/ (тесты, отдельно от главной папки, так как не нужны для работы пректа)
    ├── __init__.py
    ├── test_orders.py
    └── test_report.py
```
